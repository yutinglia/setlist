# 全站 UI／UX 重設計計畫與檢查表

## 目標

把 Setlist 重設計為以搜尋為核心的三語音樂檔案館，同時保留所有公開與管理員功能。實作以
[`design-system/setlist/MASTER.md`](../design-system/setlist/MASTER.md) 為準。

## 基線稽核

### 已經做得好的部分

- 搜尋、建議、URL 篩選條件、分頁、深層連結、情境返回、亮／暗主題、多語系與管理員守門功能完整。
- 語意 landmark、跳至內容連結、Radix 對話框／選單、載入骨架與 reduced-motion CSS 已提供良好基礎。
- 公開瀏覽、詳細頁、報表、貢獻者、法律頁與管理員路由都可直接連結。

### 需要解決的主要問題

- 常駐桌面側欄佔用內容寬度且與頂部 shell 重複，過多目的地也獲得相同視覺權重。
- 首頁、報表、資訊與管理頁大量重複同款框線卡片，缺乏明確層級。
- 歌曲／影片卡片的操作與中繼資料較分散；播放與詳細資料應更易掃讀且不能依賴 hover。
- 摘要頁把十項指標全部同等強調，降低理解速度。
- 375px 實測有多個可見連結與圖示操作只有 32–40px，高度未達 44px 目標。
- 重設計意外取代了已確認的紅／中性色產品識別。核准的紅色色票、favicon 與瀏覽器／PWA
  色彩必須視為品牌不變條件；版面與互動仍可持續演進。

## 範圍與路由清單

- 公開探索：`/`、`/search`、`/channels`、`/channels/:channelId`、
  `/videos/:videoId`、`/songs/:songId`、`/updates`。
- 公開資訊：`/summary`、`/thanks`、`/how-to-use`、`/about`、`/terms`、
  `/privacy`、`/copyright` 與找不到頁面。
- 私有操作：`/admin/login`、`/status`、`/channels/new`、登入後導覽、頻道更新、
  歌單重抓與收錄佇列狀態。
- 共用行為：頁首／選單、手機導覽、頁尾、主題／語言、API 狀態、查詢狀態、篩選、
  卡片、徽章、分頁與 metadata。
